# DentaLizi

**הדרך שלך לרפואת שיניים!**

DentaLizi הוא אתר תרגול חינמי, בעברית מלאה ובפריסת RTL, המיועד למועמדות/ים ללימודי רפואת
שיניים המתכוננים למבחני הקבלה. האתר כולל תרגול שאלות במתמטיקה ובכימיה, כל שאלה עם פתרון
מלא ומפורט בעברית, וכן סימולציה מלאה בתנאי זמן שמדמה את מבנה מבחן הקבלה.

## מה יש באתר

- **דף בית** עם קישורים לשלושת האזורים באתר.
- **מתמטיקה** - תרגול לפי נושא (בעיות הספק, גיאומטריה, בעיות תנועה, הסתברות) + מצב ערבוב.
- **כימיה** - תרגול לפי נושא (סטוכיומטריה, מבנה וקישור, חמצון חיזור, אנרגיה) + מצב ערבוב.
- **סימולציה מלאה** - בחינה משולבת: 20 שאלות מתמטיקה (טיימר של שעה) ו-30 שאלות כימיה
  (טיימר של שעה וחצי), עם אפשרות לבחור באיזה חלק להתחיל, ועם מסך תוצאות וסקירת פתרונות
  בסיום.

כל שאלה מלווה בפתרון שלב-אחר-שלב בעברית. במצב תרגול מוצג משוב מיידי על כל תשובה; במצב
סימולציה לא מוצג משוב עד להגשת החלק, בדומה למבחן אמיתי.

## טכנולוגיה

אתר סטטי לחלוטין - HTML, CSS ו-JavaScript טהורים (Vanilla), ללא כלי בנייה, ללא שרת וללא
מסד נתונים. בנקי השאלות שמורים כקבצי JS נפרדים לפי נושא תחת `data/`, כך שקל להוסיף או
לערוך שאלות בעתיד.

```
DentaLizi/
  index.html                    דף הבית
  math/index.html                בחירת נושא במתמטיקה
  chemistry/index.html            בחירת נושא בכימיה
  practice.html                    מסך תרגול גנרי (לפי נושא או ערבוב)
  simulation.html                   הסימולציה המלאה
  css/style.css                     עיצוב האתר (RTL מלא)
  js/
    quiz-engine.js                  מנוע השאלון (תצוגה, טיימר, ציון, סקירה)
    topics.js                        מטא-דאטה של הנושאים בכל מקצוע
    topic-page.js                     בניית עמודי בחירת נושא
    practice.js                       לוגיקת עמוד התרגול
    simulation.js                      לוגיקת הסימולציה המלאה
  data/
    math/{rate,geometry,motion,probability}.js
    chemistry/{stoichiometry,bonding,redox,energy}.js
```

## הרצה מקומית

מכיוון שהאתר טוען קבצי JS דרך תגיות `<script>` רגילות (לא ES modules), אפשר פשוט לפתוח
את `index.html` ישירות בדפדפן (לחיצה כפולה על הקובץ) - ללא צורך בשרת.

לחלופין, להרצה עם שרת מקומי (מומלץ אם יש בעיות עם הרשאות דפדפן לקבצים מקומיים):

```bash
# עם Python 3
python -m http.server 8000

# עם Node.js (npx)
npx serve .
```

ואז לפתוח בדפדפן: `http://localhost:8000`

## הוספת שאלות חדשות

כדי להוסיף שאלה, יש לפתוח את קובץ הנתונים המתאים תחת `data/math/` או `data/chemistry/`
ולהוסיף אובייקט חדש למערך, לפי המבנה:

```js
{
  id: "math-rate-9",
  question: "טקסט השאלה...",
  choices: ["תשובה א", "תשובה ב", "תשובה ג", "תשובה ד"],
  correctIndex: 0, // האינדקס (0-3) של התשובה הנכונה
  solution: "פתרון מלא שלב-אחר-שלב בעברית..."
}
```

## פריסה (Hosting) ב-GitHub Pages

האתר סטטי לחלוטין ומוכן לפריסה ישירה מהענף `main`, ללא צורך בתיקיית `/docs` או בבנייה
מוקדמת. ראו את הוראות הפריסה שנמסרו בנפרד לצורך יצירת המאגר, דחיפת הקוד, והפעלת
GitHub Pages.
