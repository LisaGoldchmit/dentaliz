# DentaLizi

**הדרך שלך לרפואת שיניים!**

DentaLizi הוא אתר תרגול בעברית מלאה ובפריסת RTL, המיועד למועמדות/ים ללימודי רפואת
שיניים המתכוננים למבחני הקבלה. האתר כולל תרגול שאלות במתמטיקה ובכימיה, כל שאלה עם פתרון
מלא ומפורט בעברית, וכן סימולציה מלאה בתנאי זמן שמדמה את מבנה מבחן הקבלה.

## מה יש באתר

- **דף בית** עם תמונת נושא, הסבר קצר על האתר, הצצה לעמוד "אודות" וקישורים לאזורי התרגול.
- **אודות** - עמוד אישי על ליזה, שהקימה את האתר.
- **מתמטיקה** - תרגול לפי נושא (בעיות מילוליות, גדילה ודעיכה, סדרות, הסתברות, גיאומטריה, גיאומטריה אנליטית, טריגונומטריה, חשבון דיפרנציאלי ואינטגרלי) + מצב ערבוב.
- **כימיה** - תרגול לפי נושא (מבנה האטום והטבלה המחזורית, קשר כימי ומבנה מולקולות, סוגי חומרים ותכונותיהם, סטוכיומטריה, אנרגיה, חמצון חיזור, חומצה בסיס, כימיה אורגנית וכימיה של מזון) + מצב ערבוב.
- **סימולציה מלאה** - בחינה משולבת: 20 שאלות מתמטיקה (טיימר של שעה) ו-30 שאלות כימיה
  (טיימר של שעה וחצי), עם אפשרות לבחור באיזה חלק להתחיל, ועם מסך תוצאות וסקירת פתרונות
  בסיום.

כל שאלה מלווה בפתרון שלב-אחר-שלב בעברית. במצב תרגול מוצג משוב מיידי על כל תשובה; במצב
סימולציה לא מוצג משוב עד להגשת החלק, בדומה למבחן אמיתי.

## טכנולוגיה

האתר בנוי ב-React עם Vite, וכולל ניתוב צד-לקוח (react-router-dom). אין שרת ואין מסד
נתונים - בנקי השאלות שמורים כקבצי JS נפרדים לפי נושא תחת `src/data/`, כך שקל להוסיף או
לערוך שאלות בעתיד.

```
DentaLizi/
  index.html                      נקודת הכניסה של Vite
  vite.config.js                   הגדרות בנייה (כולל base ל-GitHub Pages)
  src/
    main.jsx                        טעינת האפליקציה והראוטר
    App.jsx                          הגדרת כל המסלולים
    styles/style.css                  עיצוב האתר (RTL מלא)
    components/
      Layout, Header, Footer, Breadcrumb
      Quiz.jsx                        מנוע השאלון (תרגול + בחינה, כולל טיימר)
      ResultsReview.jsx                מסך תוצאות וסקירת פתרונות
    pages/
      Home, About, TopicPicker, Practice, Simulation
    data/
      topics.js                        מטא-דאטה של הנושאים + חיבור בנקי השאלות
      math/*.js  chemistry/*.js         בנקי השאלות, קובץ לכל נושא
```

## הרצה מקומית

```bash
npm install     # פעם ראשונה בלבד
npm run dev     # שרת פיתוח מקומי
```

ואז לפתוח בדפדפן את הכתובת שמוצגת בטרמינל (בדרך כלל `http://localhost:5173`).

לבנייה מקומית של גרסת הייצור: `npm run build`, ולתצוגה מקדימה שלה: `npm run preview`.

## הוספת שאלות חדשות

כדי להוסיף שאלה, יש לפתוח את קובץ הנתונים המתאים תחת `src/data/math/` או
`src/data/chemistry/` ולהוסיף אובייקט חדש למערך, לפי המבנה:

```js
{
  id: "math-rate-9",
  question: "טקסט השאלה...",
  choices: ["תשובה א", "תשובה ב", "תשובה ג", "תשובה ד"],
  correctIndex: 0, // האינדקס (0-3) של התשובה הנכונה
  solution: "פתרון מלא שלב-אחר-שלב בעברית..."
}
```

## פריסה (Hosting) ב-GitHub Pages

הפריסה אוטומטית: כל דחיפה לענף `main` מריצה את `.github/workflows/deploy.yml`, שבונה את
האתר ומפרסם את תיקיית `dist/` ל-GitHub Pages.

הגדרה חד-פעמית: בהגדרות המאגר, תחת Settings ← Pages, יש לבחור ב-Source את
"GitHub Actions".
